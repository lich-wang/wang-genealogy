## 范围与排除

同步器只用既有 `CBDB:<id>` 识别同一人物，绝不按姓名自动合并。仅占位名、无效生卒数据和无法证明为历史人物的记录不写入公开库；同名与异名不是排除条件。本次排除：既有 CBDB ID 13,366、无效/占位名 3,894、历史时期依据不足 862。

历史性依据依次为：1950 年前卒年、1850 年前生年，或终年早于 1950 年的朝代；不满足者不公开。新增记录未导入亲属边，避免仅从自动化名录推断世系关系。
